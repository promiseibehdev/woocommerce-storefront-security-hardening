# Phase 7 Screenshot Plan

No screenshots are captured in Phase 6. Final release assets must be real captures from
the verified Streamlit Community Cloud production URL.

## Required captures and filenames

1. `store-home-shop.webp` — Store Home or Shop with featured products and filters.
2. `product-details.webp` — Product description, price, stock, rating, and related items.
3. `checkout-simulation.webp` — Cart/checkout totals and visible no-real-payment warning.
4. `security-overview.webp` — 35-before, 83-after, +48, band, findings, and controls.
5. `components-findings.webp` — Component lifecycle/risk or filtered findings.
6. `hardening-reports.webp` — Quick wins/completed/remaining or comparison/download.

## Recommended four for README and portfolio

1. `store-home-shop.webp`
2. `checkout-simulation.webp`
3. `security-overview.webp`
4. `hardening-reports.webp`

This set communicates commerce, safe checkout, security methodology, and remediation.

## Capture requirements

- Use production, not localhost.
- Desktop viewport near 1440px for primary images; optionally add mobile evidence.
- Hide browser profile, bookmarks, local paths, notifications, and unrelated tabs.
- Load only deterministic fictional sample data.
- Verify no real person, email, address, order, credential, or payment detail is visible.
- Crop consistently without removing simulator/no-payment/certification context.
- Prefer WebP at a readable resolution and practical repository size.
- Add meaningful Markdown alt text when embedding.
- Do not use mockups, AI-generated screenshots, or temporary localhost captures.
